- 当前版本：`app.js?v=1.4.0`、`styles.css?v=1.0.24`

---

## 1. 目标与范围

**目标**

1. 把「去色罩」从逐帧拉伸改成**整卷估计**，让同卷各帧使用同一套密度锚点，消除帧间明暗/色彩跳动。
2. 提供两种可切换的整卷方法：**dmin+dmax 双锚点**与**特性曲线**，保留原逐张逻辑作为对照。
3. 保持纯前端、无上传、单文件静态部署的约束。

**不在范围**

- 三合一（RGB 分色）输入、真正的 Status M 光谱密度测量（本项目只做 Dmin/Dmax 密度锚点近似）、HDR 多曝光合成（16bit 导出已实现，但输入仍是单张 8bit 扫描）。

## 2. 物理模型与符号

以**片基**（未曝光但已显影的低密度区）为参考，逐通道做归一化：

```
T_c  = ( linear(px_c) + 0.0005 ) / max(0.018, linear(base_c))      // 相对透光率
d_c  = -log10( min(1, T_c) )                                        // 光学密度，片基处 d = 0
```

- `linear()` 为 sRGB EOTF 反变换；`base_c` 为该帧的片基值（用户取样 / 自动识别 / 高分位兜底）。
- 片基是"没有曝光"的区域，对应原场景的黑场，因此 **d = 0 → 输出 0（黑）**，密度越高越亮。
- 彩色负片的橙色色罩本质是**三个通道的 dmin 各不相同**；逐通道以各自片基归一后，橙色偏移被抵消，无需额外"减去橙色"。

输出值 `v ∈ [0,1]` 为线性光，后续沿用既有的曝光、黑白场、gamma、饱和度调整链。

## 3. 算法设计

### 3.1 整卷密度统计

```
每帧：解码到长边 480px → 逐像素（按步长抽样，上限 40 万）：
  跳过 alpha=0
  跳过 luma < 10（纯黑边框）或 luma > 248（过曝白）
  逐通道计算 d，跳过 d < 0.03（片基及比片基更亮，不含画面信息）
  累加进 hist[c][ round(d / 0.005) ]        // 512 桶，覆盖 d ∈ [0, 2.56]
```

- 直方图挂在队列项上（`item.rollHist`），切换方法、重算锚点不再重复解码。
- 未打开过的帧没有用户/自动片基，改用**逐通道 99.5% 高分位**估片基（下限 8）。这比在 480px 缩略图上跑边缘检测稳——缩略后片边太窄容易被误判成画面。
- 用户手动取样或自动识别片基后，清空该项缓存并重建。

### 3.2 锚点估计

对合并后的整卷直方图，逐通道求：

| 锚点 | 取值 | 说明 |
|---|---|---|
| dmin | 0（构造保证） | 片基归一后恒为 0 |
| dmax | 密度 99.6% 分位，clamp 到 [0.30, 2.40] | 整卷高密度参考；不是胶片物理 Dmax |
| dmid | 密度 50% 分位，clamp 到 [0.30·dmax, 0.92·dmax] | 整卷中间调 |
| nmid | `dmid / dmax`，clamp 到 [0.12, 0.90] | 中间调在归一轴上的位置 |

### 3.3 方法 A：dmin+dmax（默认）

```
n = d / dmax            // 0 = 片基黑场，1 = 整卷最密（白）
v = softShoulder(clamp(n, 0, 1.15))
```

等价于把每通道的 [片基, 整卷最密] 线性拉伸到 [0, 1] 后再做高光软肩。整卷双锚点保证同卷一致。

### 3.4 方法 B：特性曲线

以整卷中间调为拐点的两段斜率（趾部 / 肩部）：

```
n < nmid :  v = 0.18 * n / nmid
n ≥ nmid :  v = 0.18 + 0.82 * (n - nmid) / (1 - nmid)
```

- 中间调固定落在 **18% 线性灰**（≈ sRGB 118），对应胶片"中灰"约定。
- 两段斜率即 SoftLoaf 模型里的 `slopeLoR/G/B` 与 `slopeHiR/G/B`，本项目由整卷分位自适应求出，不使用固定常数。
- 相比方法 A，特性曲线在中低调的过渡更连贯，但整体更"厚"（实测同图均值 121 vs 163）。

### 3.5 高光软肩

```
knee = 0.94
n > knee : v = knee + (1-knee) * tanh((n-knee)/(1-knee)) / tanh(1)
```

- 端点精确：`n=0 → 0`、`n=1 → 1`，片基仍压成纯黑，不会抬黑位。
- 只压缩接近"最密"的过渡，避免高密度区被硬裁成死白。

### 3.6 与既有调整链的关系

- 白平衡增益改为在**去色罩映射后**的线性值上统计（`whiteBalanceGains(data, base, levels, conv)`），否则增益会把色罩残留当成偏色。
- 整卷模式下 `analysis.levels = null`（不再做逐帧黑白场拉伸），避免二次拉伸破坏一致性。
- 正片直通（`positive = true`）不走去色罩，保持原样。

## 4. 数据流与缓存

```
addFiles / 删除队列项 / 片基变更 / 方法切换
        │
        └─ scheduleRollRebuild()（120ms 防抖，立即置 rollPending=true）
                 │
                 └─ rebuildRollModel()
                        ├─ 遍历 state.queue → itemDensityHist(item)  ← 命中 item.rollHist 直接复用
                        ├─ 合并直方图
                        ├─ buildDemaskModel(method, merged) → state.demaskModel
                        └─ reanalyzeCurrent() → analyze() → scheduleRender()
```

- `rollToken` 递增用于取消过期任务（快速切换方法时只保留最后一次结果）。
- `state.demaskModel` 为全局单例；所有帧渲染、单张导出、批量导出都读取它，保证预览与导出完全一致。
- `analyze()` 内部判断 `state.demaskModel`：存在则构造 `conv = makeDemask(model, base)` 并写入 `analysis.demask`。

## 8. 与 SoftLoaf Negative 的对照

### 8.1 官方指南要点

- 推荐**整卷转换**，逐张拟合"不推荐日常使用"（缺片基、缺密度范围、缺中性色 → 帧间不一致）
- 无色卡时先用 **dmin+dmax**；有可靠卷内色卡再用色卡识别
- **特性曲线**方法利用整卷信息估计通道响应，改善不同密度下的颜色/影调衔接
- Dmin 选干净未曝光的片基，**不能用齿孔或灯箱替代**；分析框要排除齿孔、灯箱、异常片边
- 高密度参考 ≠ 胶片物理 Dmax，也不是"必须变纯白"的位置

### 8.2 本项目实现情况

| 能力 | SoftLoaf | 本项目 | 差异说明 |
|---|---|---|---|
| 整卷 dmin+dmax | ✅ | ✅ 默认 | 本项目的 dmax 取整卷密度 99.6% 分位 |
| 特性曲线 | ✅ | ✅ | 本项目用两段斜率 + 18% 中灰，SoftLoaf 另有灰轴正则 |
| 逐张处理 | ✅（不推荐） | ✅ 保留 | 原逻辑，用于对照 |
| 光谱法（Spectral） | ✅ | ❌ | 需要胶片/光源光谱数据，暂不做 |
| 卷内色卡识别 | ✅ | ✅ 手动框选 | 依次点选色卡四角 → 按 6×4 切 24 格截尾均值取样 → ColorChecker Classic 参考值最小二乘解 CCM；未做自动色卡检测 |
| 手动整卷 Dmin/Dmax 取样 | ✅ | ⚠️ 部分 | 本项目的手动取样按帧，再汇入整卷统计 |
| 排除某帧出整卷分析 | ✅ | ✅ | 队列卡片左下角「排除」按钮，被排除帧不参与整卷锚点统计，诊断输出 `excluded` 名单 |
| 灰轴正则（kRegGref）/ 中性密度偏置 | ✅ | ✅ 近似 | 「中性平衡」滑杆（0–100%，默认 35%）把三通道整卷中间调往均值靠拢，逐通道增益限幅 0.55–1.8，仅对 dmin+dmax 生效 |
| 平场校正 | ✅ | ✅ 近似 | 载入均匀空片参考，逐通道线性增益 + 双线性采样，强度 0–100% 可调；只作用于成片映射，不参与整卷锚点统计 |
| CCM 应用 | ✅ | ✅ 近似 | 3×3 矩阵在去色罩归一化线性域应用，白点保持 + 岭回归 + 系数限幅，强度 0–100% 混合；仅整卷模型下可用 |
| 镜头校正 | ✅ | ✅ 手动 | 单参数径像模型 `r' = r·(1+k·r²)`，双线性反采样，滑块 ±100（k 上限 ±0.35），负值桶形、正值枕形；不做自动参数反解 |
| 密度目标（APD / Status M） | ✅ | ✅ 近似 | 提供「黑场密度 Dmin / 白场密度 Dmax」锚点，替换整卷统计锚点做 `n=(d−Dmin)/(Dmax−Dmin)` 映射；不是光谱意义下的 Status M 密度 |
| 逐帧 AE | ✅ | ⚠️ 等效 | 用逐帧曝光/黑白场调整近似 |
| HDR / 16bit 导出 | ✅ | ✅ 16bit PNG | 宽色深渲染后按 16bit sRGB 编码（IHDR 位深 16 / truecolor），避免 8bit 中间量化；不是 HDR 多曝光合成 |

### 8.3 逆向得到的结构证据

`softloaf_negative.exe`（MSVC C++ + Qt，无 PDB）无法还原具体数值常数，但字符串/RTTI 里有：

- 转换方法枚举：`Spectral` / `Per-frame` / `Dmin+Dmax` / `Color Chart`
- 整卷模型字段：`globalDMin`、`exposureAxisLow/High`、`densityScale`、`densityClipLo`、
  `slopeLoR/G/B`、`slopeHiR/G/B`、`neutralDensityOff`、`floorShift`、`anchorReg`、
  `pcaCenter/principalAxis`（色罩主方向）、`kRegGref`
- 密度域常量：`SOFTLOAF_DENSITY_KNEE / CEIL / EPS`
- 内嵌 HLSL/Metal 内核只处理局部影调与颗粒，去色罩在 CPU 侧

本项目按上述结构对齐了「整卷 + 双锚点 + 每通道两段斜率」骨架，未编造具体常数。

## 9. 与「三合一（trichrome）」的关系

三合一是**采集端**技术：固定胶片与相机，分别只开 R / G / B 灯各拍一张，取对应通道合成为一帧线性 RGB，再走 CCM 与负片转换。它与去色罩是流程上下游的两个独立环节：

| 维度 | 三合一 | 本项目去色罩 |
|---|---|---|
| 位置 | 输入采集 | 负片转换 |
| 解决的问题 | 用窄带分时照明改善染料区分与校准稳定性 | 消除橙色色罩、建立密度→正像映射 |
| 依赖 | 三灯 + 定位稳定的翻拍设备 | 一张已合成的 RGB 图 |
| 与整卷关系 | 合成后仍要做整卷转换 | 本身就是整卷转换 |

**结论：两者不冲突也不替代。** 本项目只接受单张 RGB 输入，不做分色合成；如果用户已用三合一拍好并合成，得到的仍是普通 RGB 负像，可直接用本工具的去色罩处理。

## 10. 已知限制与后续可选

1. 灰轴正则是全局标量近似（三通道中间调拉齐），并非 SoftLoaf 的 PCA 主方向 + 参考灰梯度正则。
2. 无卷内色卡与光谱法；对染料串扰严重的胶片只能靠经验调色。
3. dmax 固定取 99.6% 分位，极端卷（大量纯黑边框未滤净）可能偏高，表现为画面偏灰。
4. 特性曲线以 18% 灰为中点，是通用约定，不区分胶片型号。
5. 16bit PNG 只是输出端宽色深：输入扫描仍是 8bit，真正的高位深采集需要 16bit 源文件。
6. 平场参考需要与待处理帧同一光路拍摄；参考图与画面尺寸不一致时按归一化坐标拉伸采样。
7. 色卡 CCM 依赖用户手动点四角，且按 ColorChecker Classic 布局；色卡类型不同或拍摄角度过大时解算误差会明显上升。
8. 镜头校正为单参数径像模型，未建模切向畸变与镜头本征色差；滑块会重置当前帧的透视与裁剪。
9. 密度目标只是黑白场密度锚点，不是 Status M 光谱密度测量，不能替代标准密度计读数。
